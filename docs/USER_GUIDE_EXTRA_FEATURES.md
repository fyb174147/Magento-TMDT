# Huong dan tinh nang bo sung

## Thanh toan

Tai checkout co 2 cach thanh toan:

- Cash On Delivery: khach thanh toan khi nhan hang.
- Chuyen khoan VietQR: khach quet QR, chuyen dung tong tien don hang, sau do dat hang.

## Van chuyen

Tai checkout co 2 cach van chuyen:

- Flat Rate: phi co dinh.
- Giao hang nhanh Bookstore: phi tinh theo so luong sach trong gio.

## Trang tien ich

Mo `/bookstore-info` de xem:

- Thoi tiet hien tai tu OpenWeatherMap.
- Ty gia USD, EUR, JPY, AUD, GBP tu Vietcombank.
- Tin kinh doanh moi tu RSS VnExpress.

## API

Dung Postman hoac curl de goi:

```bash
curl http://localhost/rest/V1/bookstore/catalog/products
curl http://localhost/rest/V1/bookstore/catalog/categories
```
